# dsh-agnes-create

在 DeepSeek Harness（dsh）里直接**出图**和**出视频**的侧边栏插件。侧边栏点一下「Agnes创作」，输入提示词就能出片，结果自动保存到本地并可在面板里回看。

> 仓库：<https://github.com/zxygithub/dsh-agnes-create>　·　npm：`dsh-agnes-create`

- 出图：`agnes-image-2.5-flash` — 支持 `1K`/`2K`/`3K`/`4K` 与 8 种宽高比
- 出视频：`agnes-video-2.5-flash` — 720P，4–12 秒，异步任务带百分比进度
- Key 文件位置、输出目录都能在界面里改，改完即时生效
- 最近 8 条生成结果可回看，一键清空界面（不删文件）

## 安装

在插件市场里搜 `dsh-agnes-create` 安装，或命令行：

```bash
dsh plugin --profile <profile> add dsh-agnes-create
```

装好后面板出现在左侧边栏，标签为 **Agnes创作**。

## 准备 API Key

插件从文件读取 Key，**不接受把 Key 写在配置里或代码里**。默认路径：

```
~/.agnes-key.txt
```

文件里只放 Key 本身，不要带 `Bearer ` 前缀、不要加引号：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

Key 从 [Agnes AI 平台](https://platform.agnes-ai.com) 获取。端点默认走中国站 `https://api.agnes-ai.cn/v1`。

## 配置

面板底部的「设置」卡片可以改两项，保存后立即生效（不用重启）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| Key 文件路径 | `~/.agnes-key.txt` | 支持 `~/` 开头或绝对路径 |
| 输出目录 | `~/Desktop/Agnes出图` | 图片和视频都存这里，不存在会自动创建 |

- 输入框留空并保存 = 回退到默认值
- 配置存在 `~/.dsh/agnes-image/config.json`
- 优先级：显式传参 > 已保存配置 > 环境变量（`AGNES_KEY_FILE` / `AGNES_OUT_DIR`）> 默认值
- 配置文件损坏时会静默回退默认值，不会让插件加载失败

## 用法

1. 侧边栏点 **Agnes创作**
2. 顶部选择 **图片** 或 **视频**
3. 输入提示词，`Cmd/Ctrl + Enter` 或点按钮生成
4. 结果直接显示在面板里；图片用 `<img>`、视频用 `<video>` 播放（支持拖动进度条）

提示词建议按「主体 + 场景 + 动作/镜头 + 光线 + 风格 + 构图」组织，例如：

```
一只胖乎乎的橘色虎斑猫坐在木质窗台上，午后暖阳斜射，窗外虚化的街景，浅景深，写实摄影，中景构图，高细节
```

参数范围：

| 类型 | 尺寸 | 宽高比 | 其它 |
| --- | --- | --- | --- |
| 图片 | `1K` `2K` `3K` `4K` | `1:1` `3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` | — |
| 视频 | 固定 `720P` | `21:9` `16:9` `4:3` `1:1` `3:4` `9:16` | 时长 4–12 秒 |

## 关于费用

插件的费用由 Agnes AI 账号结算，本插件不涉及任何计费。

- 图片：1K 刊例价约 `$0.010/张`，2K 约 `$0.018/张`
- 视频：`$0.025/秒`（4 秒约 `$0.10`）

官方文档标注当前为体验价（`$0`）。具体以平台公告为准。

## 已知限制

- 视频为**异步任务**：提交后轮询，通常需要 1–4 分钟；队列繁忙时提交会返回 `503`，插件会自动重试
- 查询接口有频率限制，触发 `429` 时面板会显示「限流重试中…」并退避，任务不会因此失败
- 只支持文生图 / 文生视频，暂未接图生图、首尾帧与参考音频
- 生成结果只保留最近 8 条（本次会话内），刷新页面后历史清空；文件本身在输出目录里不会丢

## 开发

包内是纯 ESM，**没有构建步骤**：`lib/client.js` 是手写的客户端 bundle（`window.__ModuleLoader__.load` 包装），宿主侧 `lib/index.js` 注册 HTTP 路由，`lib/agnes.js` 是与命令行共用的内核。

```
lib/
├── agnes.js    内核：请求构造、视频任务轮询、落盘、配置解析
├── index.js    宿主半：/agnes/health /agnes/config /agnes/generate /agnes/video /agnes/media
└── client.js   客户端半：侧边栏入口 + 面板 UI
cordis.patch.yml  把插件行插入 profile
```

改动后无需构建，重载窗口即可生效；宿主路由的改动需要重启应用。
