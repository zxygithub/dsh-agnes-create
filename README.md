# dsh-agnes-create

在 DeepSeek Harness（dsh）里直接**出图**和**出视频**的侧边栏插件。侧边栏点一下「Agnes创作」，输入提示词就能出片，结果自动保存到本地并可在面板里回看。

> 仓库：<https://github.com/zxygithub/dsh-agnes-create>　·　npm：`dsh-agnes-create`

- 出图：`agnes-image-2.5-flash` — 支持 `1K`/`2K`/`3K`/`4K` 与 8 种宽高比
- 出视频：`agnes-video-2.5-flash` — 720P，4–12 秒，异步任务带百分比进度
- Key 文件位置、输出目录都能在界面里改，改完即时生效
- 最近 8 条生成结果可回看，一键清空界面（不删文件）

## 安装

在插件市场里搜 `dsh-agnes-create` 安装，或命令行：

```bash
dsh plugin --profile <profile> add dsh-agnes-create
```

装好后面板出现在左侧边栏，标签为 **Agnes创作**。

## 准备 API Key

插件从文件读取 Key，**不接受把 Key 写在配置里或代码里**。默认路径：

```
~/.agnes-key.txt
```

文件里只放 Key 本身，不要带 `Bearer ` 前缀、不要加引号：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

Key 从 [Agnes AI 平台](https://platform.agnes-ai.com) 获取。端点默认走中国站 `https://api.agnes-ai.cn/v1`。

## 配置

面板底部的「设置」卡片可以改两项，保存后立即生效（不用重启）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| Key 文件路径 | `~/.agnes-key.txt` | 支持 `~/` 开头或绝对路径 |
| 输出目录 | `~/Desktop/Agnes出图` | 图片和视频都存这里，不存在会自动创建 |

- 输入框留空并保存 = 回退到默认值
- 配置存在 `~/.dsh/agnes-image/config.json`
- 优先级：显式传参 > 已保存配置 > 环境变量（`AGNES_KEY_FILE` / `AGNES_OUT_DIR`）> 默认值
- 配置文件损坏时会静默回退默认值，不会让插件加载失败

## 用法

1. 侧边栏点 **Agnes创作**
2. 顶部选择 **图片** 或 **视频**
3. 输入提示词，`Cmd/Ctrl + Enter` 或点按钮生成；提示词上方有 6 个风格预设（写实摄影 / 水彩 / 3D 渲染 / 海报 / 夜景霓虹 / 极简），点一下追加到末尾，不会冲掉已写的主体
4. 想放弃等待就点生成按钮旁的 **取消**（只是停止本地等待，服务端任务可能仍在跑）
5. 结果直接显示在面板里；图片用 `<img>`、视频用 `<video>` 播放（支持拖动进度条）
6. 结果下方三个按钮：**复制路径**（写到剪贴板）、**在访达中显示**（定位到文件）、**下载**（另存一份到「下载」目录）；如果结果本身是图片，还会多出 **设为首帧** / **设为尾帧**，一键把它变成下一段视频的关键帧
7. 生成过的内容记在面板底部「最近生成」里，最多 24 条，落盘到 `~/.dsh/agnes-create/history.json`，重启应用也不丢

提示词建议按「主体 + 场景 + 动作/镜头 + 光线 + 风格 + 构图」组织，例如：

```
一只胖乎乎的橘色虎斑猫坐在木质窗台上，午后暖阳斜射，窗外虚化的街景，浅景深，写实摄影，中景构图，高细节
```

参数范围：

| 类型 | 尺寸 | 宽高比 | 其它 |
| --- | --- | --- | --- |
| 图片 | `1K` `2K` `3K` `4K` | `1:1` `3:4` `4:3` `16:9` `9:16` `2:3` `3:2` `21:9` | 可选 1–8 张参考图（图生图 / 多图合成） |
| 视频 | 固定 `720P` | `21:9` `16:9` `4:3` `1:1` `3:4` `9:16` | 时长 4–12 秒，可选首帧 / 尾帧，可选 seed |

### 图生图 / 多图合成

「参考图」区有两种来源，可以混着加，最多 8 张：

- **＋ 本地图片** —— 从磁盘选一个或多个文件（PNG / JPEG / WebP / GIF）
- **＋ 生成结果** —— 从下方「最近生成」里挑一张（视频不能当参考图）

加好之后提示词写「想怎么改」，按钮会变成 **图生图**：

| 参考图数量 | 实际行为 |
| --- | --- |
| 0 张 | 纯文生图 |
| 1 张 | 图生图（按参考图重绘 / 改风格 / 换背景） |
| 2–8 张 | 多图合成（把多张图的元素 / 配色融合） |

实现细节：

- 图片在**浏览器侧先下采样到长边 1280** 再编码成 data URI（PNG 优先保留透明通道，超过 800 KB 自动转 JPEG），所以一张 4K 原图发出的请求也只有几百 KB
- 参考图走接口的 `extra_body.image`；多图就是往这个数组里放多条
- 校验在前端和内核各做一次：只接受 `http(s)` 或 `data:image/…;base64`，超过 8 张、空串、非图片类型都会直接报错，不会把脏数据发给上游
- 本地文件路径**不会**被读取或上传到别处：文件内容只在内存里转成 base64 随请求发给 Agnes

### 图生视频（首帧 / 尾帧）

视频模式多出「关键帧」一栏，可以给**首帧**、**尾帧**各选一张图片，也可以只给一张。图片来源有三种：

- **＋ 本地** —— 从磁盘选（PNG / JPEG / WebP / GIF）
- **＋ 结果** —— 从「最近生成」里已经出过的图片中挑一张（没有生成过图片时按钮是灰的）
- **结果下方「设为首帧 / 设为尾帧」** —— 当前这张结果图直接变成关键帧，切回视频模式就能看到

| 给了什么 | 实际行为 |
| --- | --- |
| 都不给 | 纯文生视频（和以前一样） |
| 只给首帧 | 从这张图开始动 |
| 只给尾帧 | 向这张图收尾 |
| 首帧 + 尾帧 | 从首帧过渡到尾帧（时长决定过渡的快慢） |

- 关键帧同样在浏览器侧压到长边 1280 再编码成 data URI，**直接以 base64 发给上游**，不需要先传到公网图床，本地图片可以直接用
- 「种子」是可选的非负整数：同一个提示词配同一个 seed 更容易得到相近的结果，留空则由服务端随机；结果下方会显示实际用的 seed

> 关键帧只在视频模式出现；图片模式用的是上面的「参考图」。

### 提示词随图保存

出图时会把这次的提示词写进图片文件本身（PNG 用 iTXt 块、JPEG 用 COM 段），所以：

- 在面板里把鼠标移到结果图上，底部会浮出当初的提示词，点「复制」就能拿到；
- 用系统看图软件、Photoshop、exiftool 打开也能看到这段文字——不依赖本插件；
- 只对新生成的图片生效；视频不写（mp4 元数据没有通用写法）。

### 浏览输出目录

结果卡片右上角的 **输出目录** 按钮会把输出目录里已经存在的文件列成缩略图：

- 分「图片 / 视频」两页，各带数量；
- 点任意一张就把它显示到上方结果区，图片会连带读回当初写在文件里的提示词；
- 只读不写，不会改动或删除你的文件；「刷新」用于同步新生成的文件。

## 关于费用

插件的费用由 Agnes AI 账号结算，本插件不涉及任何计费。

- 图片：1K 刊例价约 `$0.010/张`，2K 约 `$0.018/张`
- 视频：`$0.025/秒`（4 秒约 `$0.10`）

官方文档标注当前为体验价（`$0`）。具体以平台公告为准。

## 已知限制

- 视频为**异步任务**：提交后轮询，通常需要 1–4 分钟；队列繁忙时提交会返回 `503`，插件会自动重试
- 查询接口有频率限制，触发 `429` 时面板会显示「限流重试中…」并退避，任务不会因此失败
- 视频暂不支持参考音频与参考视频输入（Flash 版接口本身不支持）；图生视频目前只走首帧 / 尾帧关键帧
- 参考图最多 8 张；单张在浏览器侧压到长边 1280，细节极多的小字参考图重绘后可能看不清
- 生成历史保留最近 24 条，落盘到 `~/.dsh/agnes-create/history.json`；点「清空」会同时清掉磁盘记录，但已生成的文件仍在输出目录里

## 开发

包内是纯 ESM，**没有构建步骤**：`lib/client.js` 是手写的客户端 bundle（`window.__ModuleLoader__.load` 包装），宿主侧 `lib/index.js` 注册 HTTP 路由，`lib/agnes.js` 是与命令行共用的内核。

```
lib/
├── agnes.js    内核：请求构造、视频任务轮询、落盘、配置解析
├── index.js    宿主半：/agnes/health /agnes/config /agnes/generate /agnes/video /agnes/media
└── client.js   客户端半：侧边栏入口 + 面板 UI
cordis.patch.yml  把插件行插入 profile
```

改动后无需构建，重载窗口即可生效；宿主路由的改动需要重启应用。
